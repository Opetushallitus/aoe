# Infrastructure

- Production: AWS ECS Fargate, Aurora (PostgreSQL), ElastiCache (Redis), OpenSearch
- The frontend is not on ECS: it is static files in `aoe-frontend-<env>`, served by CloudFront's default behavior over Origin Access Control, with an explicit behavior forwarding each backend path to the ALB. See [ecs-services-overview.md](ecs-services-overview.md).
- ECS task, service and deployment events (e.g. a stopped task's `stoppedReason`) are kept in CloudWatch Logs under `/aws/events/ecs/containerinsights/<env>-ecs-fargate/performance`, the console's event capture log group
- ECS Action Logs (every step ECS takes during a deployment) are enabled per cluster and kept for 30 days under `/aws/vendedlogs/ecs/action-logs/<env>-ecs-fargate`. `<env>-web-backend-DeploymentFailedAlarm` fires when the deployment circuit breaker rolls back a backend deployment, and its description links to both log groups
- web-backend runs at least two tasks in dev and qa (`min_count: 2`, `max_count: 3` in `aoe-infra/environments/<env>.ts`) and scales on average CPU; prod runs one task until replication is verified in qa. Sessions and OIDC state are in Redis and files on EFS, so any task can serve any request. On deploy, old tasks drain for 300 s before they get SIGTERM
- Every change in web-backend's running task count posts to the Slack channel (not PagerDuty): `<env>-web-backend-ScaledOutAlarm` when it runs more than `min_count` tasks and `<env>-web-backend-BelowMinimumAlarm` when it runs fewer (for example a task died), each again when it is back at `min_count`. Both are suppressed during deployments and for 5 minutes after them, when the changing count is the rolling update. Slack-only alarms use the `<env>-cloudwatch-slack-only` topic
- Sensitive config in AWS Parameter Store (`/<environment>/<serviceName>/`), database secrets in Secrets Manager
- Local: Docker Compose with LocalStack for S3, mock OIDC server — locally and in CI the frontend still runs in a container, so CloudFront routing is only exercised in a deployed environment
